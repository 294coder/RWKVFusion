# Unified Metrics for Image Fusion Tasks

Due to some historical resons, some metrics are implemented in MATLAB or numpy related. We re-implemented them in Python and mainly based on Pytorch for better vectorized parrallelism.

The _[fusion metrics](../../utils/fusion_index)_ are from MATLAB code MEFB code base.

The _[Pansharpening and HMIF metrics](../../utils/sharpening_index)_ are mainly based on Pan-Collection.

We hope this will help you for convient and fast evaluation.
